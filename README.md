## 🔧 What I've Built

### [Instagram Comment-to-DM Automation](https://github.com/HadiaKhan-123/Instagram-Comment-to-DM-Automation)

Detects keyword comments on Instagram → fires a public reply + private DM. Zero manual work. Runs 24/7.

**The problem it solved:**  
Meta overhauled their API in 2024. Every tutorial, blog post, and YouTube video was outdated. I rebuilt the integration from scratch using only official Meta documentation.

**Stack:** n8n · Meta Graph API · Instagram Platform API · OAuth 2.0 · ngrok · ManyChat · Node.js · Webhooks

**What I built:**
- Two-node webhook architecture (GET for verification, POST for events)
- OAuth 2.0 token flow from scratch
- Nested JSON payload parsing to extract comment data
- Full Meta App Review package for production permissions

→ [See full project](https://github.com/HadiaKhan-123/instagram-comment-to-dm) · [Live portfolio](https://hadia-khan-portfolio.netlify.app/)
